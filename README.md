
# Car Simulator - OOP Project

A C# console-based car simulator developed during my 20-week internship at Buss-IT-Labs.

## About the Project

This project simulates basic vehicle operations using object-oriented programming principles.

The user can interact with a virtual car and change its current state.

## Features

- Start and stop the engine
- Accelerate the vehicle
- Refuel the car
- Display current vehicle status
- Console-based controls

## Technologies

- C#
- .NET 10
- Console Application
- Object-Oriented Programming

## Getting Started

### Requirements

- .NET 10 SDK

### Run the Application

Open the project in Visual Studio or navigate to the project directory and execute:

```bash
dotnet run
```

## Learning Objectives

- Creating classes and objects
- Encapsulation
- Using properties and methods
- Managing object state
- Implementing conditional logic
